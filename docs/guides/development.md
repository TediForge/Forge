# Development Guide

## CI checks

The CI workflow runs the test suite and checks that `docs/openapi.json` matches
the schema generated by the API. Run the same schema check locally with:

```powershell
python scripts/generate_openapi.py --check
```

After changing API routes or models, regenerate the committed schema with:

```powershell
python scripts/generate_openapi.py --write
```

## Local inference benchmark

The benchmark requires a previously downloaded Transformers text-model
directory. It uses that local directory and does not download model weights:

```powershell
python scripts/benchmark_inference.py --model-path "<model-directory>"
```

It reports gateway initialization time, first-token latency, and completion
time for five concurrent text requests. Latencies depend on the host hardware
and model; compare results only across equivalent systems.
