# R-005: xAI Responses API

- **Date checked:** 2026-11-11
- **Purpose:** Compare the Responses-style API documented by xAI.

## Findings

xAI documents a Responses interface for text generation, reasoning, and
tool use. Similar route concepts across providers do not make those
implementations interchangeable or define Forge's backend provider.
