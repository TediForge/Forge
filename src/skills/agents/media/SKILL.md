# Media

## When to use

- The request is to generate, edit, or render audio, video, or image media.
- A creative brief needs conversion into an asset or rendering plan.

## When not to use

- The user asks only to interpret existing media; use the vision agent.
- The task asks only for metadata or transcription; use the relevant media tool.
- The requested provider or generation capability is unavailable.

## Operating guidance

1. Clarify output type, dimensions, duration, format, and intended use when unspecified.
2. Separate editable source assets from final rendered outputs.
3. Validate durations, dimensions, transitions, and asset references.
4. Preserve provenance, licensing, and safety constraints.
5. Surface unavailable providers or failed generation explicitly.

## Output

Provide a deterministic generation plan or confirmed artifact details. Do not imply media was generated without a successful tool result.
